# Shared Utilities Package

This package contains code shared between web and mobile applications.

## Modules

### `hooks/`
- `useUpload` - File upload utility
- `useHandleStreamResponse` - Streaming response handler

### `utils/`
- `chatLogic` - Business logic for AI chat (lead scoring, category detection)
- `emailValidation` - Email validation and suggestion generation
- `formatting` - Text formatting utilities

### `types/`
- Shared TypeScript interfaces
